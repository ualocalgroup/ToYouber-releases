# ToYouber — завантаження та оновлення

Відео й музика, бібліотека, обрізання, вбудований плеєр. Інтерфейс українською та англійською.

**[Завантажити актуальну версію для macOS](https://github.com/ualocalgroup/ToYouber-releases/releases/latest)**

| Платформа | Версія | Доступність |
| --- | --- | --- |
| macOS 12+ | 1.3 build 30 | DMG, Intel x86_64 runtime; Apple Silicon через Rosetta. Ad-hoc підпис, без notarization |
| Windows 10/11 x64 | 1.2.16 preview | Попередній інсталятор із вибором папки; відстає від macOS. Запуск на Windows ще не підтверджений |
| Android 8+ | 1.2 preview (code 3) | Попередня debug-підписана APK, arm64-v8a/x86_64. Перевірка на фізичному пристрої ще потрібна |
| Linux | — | Збірка ще не доступна |

Windows/Android розміщено в [окремому preview-релізі](https://github.com/ualocalgroup/ToYouber-releases/releases/tag/legacy-preview-2026-10-20), а не в стабільному каналі. Не всі останні зміни macOS є в цих збірках.

## Встановлення

- macOS: відкрити DMG і перенести ToYouber у Applications. Перед заміною закрити стару версію. Дані старої програми зберігаються.
- Windows: запустити Setup EXE, вибрати папку й ярлики. Якщо WebView2 відсутній, для його встановлення потрібен інтернет.
- Android: відкрити APK та дозволити встановлення з обраного джерела. Preview використовує тестовий debug-ключ; майбутній release-ключ може вимагати перевстановлення, тому попередньо експортуйте завантажені файли.

## Канали оновлень

- [stable.json](https://raw.githubusercontent.com/ualocalgroup/ToYouber-releases/main/channels/stable.json) — актуальні перевірені артефакти.
- [preview.json](https://raw.githubusercontent.com/ualocalgroup/ToYouber-releases/main/channels/preview.json) — окремі тестові збірки.

Ключі платформ: `macos-x86_64`, `windows-x86_64`, `android-arm64-x86_64`, `linux-x86_64`. Запис містить версію, номер build, URL, розмір та SHA256. Відсутня платформа не має готового оновлення; не підставляйте пакет іншої ОС. SHA256 перевіряє цілісність завантаження, але не замінює підпис видавця.

Це джерело дистрибутивів і метаданих. Наявні застосунки поки **не мають самооновлення всієї програми**; кнопка оновлення рушія оновлює yt-dlp. Інтеграція перевірки й встановлення нових версій додатка — окремий наступний крок.

Вихідний код ToYouber зберігається в окремому приватному репозиторії. У цьому репозиторії немає його копії. Сторонні компоненти мають власні ліцензії: див. [THIRD_PARTY.md](THIRD_PARTY.md).
