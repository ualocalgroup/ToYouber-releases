# Holmie

Відео й музика поруч. Раніше — ToYouber; адресу репозиторію збережено для сумісності оновлень.

- [macOS, Windows x64 та Linux DEB — stable](https://github.com/ualocalgroup/ToYouber-releases/releases/tag/v1.3.93)
- [Android — native Compose preview](https://github.com/ualocalgroup/ToYouber-releases/releases/tag/android-v1.7.3-preview)

macOS ToYouber build 31+ отримує оновлення через GitHub у параметрах. Внутрішню назву ToYouber.app збережено для сумісного переходу до Holmie. Для старіших версій — ручне встановлення DMG. Підпис ad-hoc, без Apple notarization.

Windows: запусти EXE та обери папку. Linux: встанови DEB; перевірено Ubuntu 24.04 x64. Android: встанови preview APK вручну. Вбудоване встановлення оновлень Windows/Linux/Android поки не реалізоване.

Контрольні суми — SHA256SUMS.txt. Android preview містить відповідні відкриті вихідні коди сторонніх компонентів та інструкції їх заміни. Код самого додатка приватний. Деталі тестів та обмеження — в описах релізів.
